# Data Directory

This repository does not include raw neuroimaging datasets, restricted HCP family metadata, or fitted model outputs.

## External Datasets

1. **ERP CORE N170**: Download from the [ERP CORE repository](https://doi.org/10.18115/D5JW4R) and place the raw MNE data and N170 artifact-parameter CSV under `data/ERP_CORE_N170/`.
2. **HCP Young Adult (Working Memory task)**: Obtain authorized access and surface resources through the [Human Connectome Project](https://www.humanconnectome.org/study/hcp-young-adult). Preprocessing requires Connectome Workbench (`wb_command`).

All files under `data/` (except this README) are ignored by `.gitignore`.
